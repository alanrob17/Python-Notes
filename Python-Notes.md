## Jupyter Notebooks

I am using pyChart to run Jupyter notebooks and want to save my notebook as a Markdown file. How can I do this?

```bash
	pip install nbconvert
```

And.

```bash
	jupyter nbconvert Day-3.ipynb --to markdown
```
